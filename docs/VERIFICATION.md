# Проверка первой версии

Дата: 12 октября 2026. Среда: Windows, Python 3.12, PostgreSQL 18. Для production в Compose выбран PostgreSQL 16; эту контейнерную версию на текущей машине не запускали.

## Автоматические проверки

Финальный прогон `TEST_DATABASE_URL=… python -m pytest -q`: **48 passed** на PostgreSQL.

Проверено:

- Создание курса, группы и ученика через HTTP-формы администратора.
- Публичная заявка и ограничение повторной отправки.
- Повторная выдача одного шаблона двум группам, разные даты и независимые попытки.
- Неизменность опубликованного снимка при редактировании банка.
- Запланированное открытие, дедлайн, разрешённое опоздание, скрытие и закрытие при открытии решений.
- Пять типов ответов: десятичная запятая/точка, знак минус, дроби, погрешность, порядок и некорректный ввод.
- Отсутствие скрытого решения в HTML до разрешённого срока.
- Запрет доступа к чужой выдаче, административным страницам, чужому балансу и файлам.
- Защита CSRF; разрешённые файлы и запрет SVG; доступ к файлам курса и снимка работы.
- Ручной зачёт с сохранённой причиной без перезаписи исходной попытки.
- Инвалидация сессии после смены пароля.
- Запись, повторное нажатие, отмена, повторная запись, ограничение аудитории и срока отмены.
- Нельзя записать другого ученика, подменив user_id в форме.
- Все пять статусов посещаемости; отсутствие списаний для бесплатного и отдельно оплачиваемого события.
- Отрицательный баланс, фактическая длительность, частичный/полный возврат, ограничение сверхвозврата, повторное подтверждение и изменение посещаемости после возврата.
- Отмена занятия преподавателем возвращает актуальное списание через историю.
- Запрет подтверждать будущее занятие или пропустить отметку участника.
- Уведомление об остатке меньше следующего занятия и его закрытие после пополнения.
- Идемпотентная отметка отдельной оплаты, без изменения абонемента.
- Четыре одновременных подтверждения дают одно списание.
- Четыре одновременных ответа не обходят лимит в одну попытку.
- Четыре одновременные записи дают одного участника.

Также выполнены `alembic upgrade head` на чистой PostgreSQL, `alembic check` (расхождений схемы нет), `pip check` (конфликтов нет), компиляция Python. Демо-данные загружены через CLI.

Тестовый клиент выдаёт одно предупреждение Starlette о будущем переходе с httpx на httpx2. Оно не является ошибкой приложения или теста.

## Что не проверено и что остаётся настроить

- Docker/Compose и скрипты backup/restore не запускались: Docker отсутствует. Проверка миграций и бизнес-логики выполнялась на локальном PostgreSQL 18.
- Не выполнялись публичная публикация, настройка DNS/HTTPS и покупка услуг. Внешние интеграции и платные ключи для этой версии не нужны.
- Реальные сведения преподавателя, контакты, программы, расписание и ссылки Google Meet вводятся в кабинете. Демо-материалы явно помечены.
- Реальные мобильные устройства, Safari и нагрузка большого класса отдельно не тестировались. Проверен адаптивный viewport встроенного Chromium.
- Пароли восстанавливает администратор; автоматических писем нет. Повторяющиеся встречи создаются по одной. Календарь представлен списком. Формы выбора порядка заданий и аудитории пока используют номера записей; большие административные списки не имеют пагинации.
- Итог задания бинарный. Видеосвязь, платежи и WhatsApp остаются внешними ручными действиями по заданной границе версии.

Временные серверы проверки останавливаются после завершения работы. Для самостоятельного просмотра используйте `scripts/dev.ps1` (SQLite-демо) либо основной запуск через Docker из README.
