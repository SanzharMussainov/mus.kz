# mus.kz — онлайн-обучение математике

Работающее серверное приложение: FastAPI, PostgreSQL, SQLAlchemy/Alembic, Jinja2, HTMX и KaTeX. Русский интерфейс, тенге, отображение расписания в Asia/Qyzylorda. PostgreSQL хранит даты как timestamptz; приложение нормализует их в UTC.

## Запуск через Docker Compose

Требуются Docker Engine / Docker Desktop с Compose v2.

1. Скопируйте `.env.example` в `.env`.
2. Задайте случайный `POSTGRES_PASSWORD` и такой же пароль в `DATABASE_URL`. Для простоты используйте случайную hex-строку без URL-спецсимволов. Задайте независимый `SECRET_KEY` длиной не менее 32 символов, например результат `python -c "import secrets; print(secrets.token_hex(32))"`. Не храните `.env` в Git.
3. Выполните:

```sh
docker compose up -d --build
docker compose exec web python -m app.cli create-admin --email your-email@example.com --name "Ваше имя"
```

Пароль вводится дважды скрыто. Откройте http://127.0.0.1:8000/login. Миграции выполняются при старте web. База не публикуется на порту хоста, сайт привязан к loopback.

Для тестовой установки без реальных данных:

```sh
docker compose exec web python -m app.cli seed-demo
```

| Демо-роль | Email | Пароль |
|---|---|---|
| Преподаватель | teacher@example.test | Teacher-demo-2026 |
| Ученик | student@example.test | Student-demo-2026 |

Все курсы и занятия демо помечены. Начисление 30 минут с нулевой суммой — тестовая запись. Команда повторно не создаёт тот же набор. **Не запускайте seed-demo на публичной рабочей установке**. Начинайте реальную работу с чистой БД и своим администратором.

Сброс пароля:

```sh
docker compose exec web python -m app.cli reset-password --email student@example.com
```

Изменение пароля инвалидирует старые сессии. Преподаватель также может задать новый пароль ученика через карточку ученика; пустое поле оставляет старый пароль.

## Локально без Docker

Python 3.12+ и PostgreSQL 16+ рекомендованы. SQLite поддерживается только для одиночного ознакомления и быстрых тестов, не для конкурентной работы учеников.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\scripts\dev.ps1
```

Скрипт создаёт `local.db`, применяет миграции, добавляет демо и запускает сервер. Если политики PowerShell запрещают запуск скрипта, выполните содержащиеся в нём команды вручную. Системные политики менять не требуется.

Для PostgreSQL перед запуском задайте `$env:DATABASE_URL='postgresql+psycopg://USER:PASSWORD@127.0.0.1:5432/DBNAME'`. База должна быть заранее создана. `.env` при запуске Python напрямую автоматически не читается: переменные задаются в оболочке. В Docker `.env` подключён через Compose.

## Работа преподавателя

1. **Информация сайта**: заполните имя проекта, заголовок, описание, сведения о преподавателе и контакты. WhatsApp — цифры с кодом страны. Реальные цены и отзывы не выдумываются.
2. **Курсы → Темы → Уроки**: подготовьте программу, формулы `\(x^2\)` / `\[...\]`, прикрепите PDF/JPEG/PNG до 10 МБ. Класс, направление и уровень — отдельные поля. SAT/NUET/ЕНТ можно добавлять как направления без изменения схемы.
3. **Ученики → Группы → Состав групп**: создайте ученика, группу и членство. Удаление из группы — снятие флажка «Состоит в группе»; исторические записи сохраняются. Прямой доступ без группы выдаётся в **Доступ к курсам**. Завершённой группе задайте «Архив».
4. **Банк заданий**: пять типов проверки. Варианты — каждый с новой строки, правильные варианты и набор чисел разделяются `;`. Числа принимают точку/запятую, дроби — `2/3`. Не используйте запятую для разделения корней. Настройте погрешность, порядок или точную форму дроби и переведите задания в «Готово».
5. **Шаблоны работ**: укажите номера заданий через запятую в нужном порядке. Кнопка копирования создаёт новый шаблон; задания в банке общие, для изменения самих заданий создайте новые записи.
6. **Выдачи работ**: выберите группу и шаблон, даты, число попыток **на каждое задание**, политику опозданий. «Опубликовано» фиксирует снимок условий, ответов, решений, правил и прикреплённых файлов. Будущее открытие происходит при наступлении даты без фонового планировщика. «Скрыто» временно закрывает доступ. Повторная публикация не пересоздаёт снимок. Для другой группы или новой редакции создайте новую выдачу. После открытия решений новые ответы не принимаются даже при разрешённых опозданиях.
7. **Занятия и события**: создайте дату, длительность и ссылку Meet. Обычное групповое занятие появляется у всех текущих участников группы. Поле расписания группы — описание; каждую встречу нужно создать отдельно. События используют отдельную запись и выбранную аудиторию. Для занятия без группы добавляйте участников вручную на его странице.
8. После занятия откройте его страницу, отметьте каждого участника и подтвердите длительность. До подтверждения списаний нет. Присутствие/пропуск без предупреждения списывает минуты; предупреждение, пробное и отмена не списывают. Изменение сохраняет отдельную корректировку. Возврат делается в абонементе со ссылкой на списание и причиной. Суммарный возврат ограничен оставшимся списанием. Возвращённые минуты учитываются как скидка при повторном подтверждении и перерасчётах посещаемости.
9. **Абонемент**: выберите ученика, внесите сумму в целых тенге, купленные минуты, дату и комментарий. 8 часов = 480 минут. Отрицательный остаток допустим; начисления не сгорают. Отдельно оплачиваемое событие отмечается на странице события, минуты не затрагиваются.
10. **Обзор**: прошедшие неподтверждённые встречи, заявки, нехватка минут и запросы, по которым ждём оплату. Скопируйте сообщение или откройте WhatsApp, отправьте вручную и отметьте «Запрос отправлен». При достаточном пополнении уведомление исчезает.
11. **Результаты**: ответы, попытки, поздние сдачи, файлы и ручное изменение зачёта с обязательной причиной. Итог работы — количество заданий, где есть хотя бы одна зачтённая попытка. Если нужно снять зачёт задания полностью, исправьте все ранее зачтённые попытки.

## Проверки

```sh
python -m pytest -q
```

Для полного прогона, включая гонки, задайте `TEST_DATABASE_URL` на отдельную тестовую PostgreSQL. Тесты создают и удаляют только случайные схемы `test_<uuid>`; пользователь БД должен иметь право CREATE SCHEMA.

На текущей машине выполнены 58 тестов в Docker на PostgreSQL 16.15, включая конкурентные запросы. Проверены миграции и восстановление копии в отдельную установку со сверкой таблиц, баланса, ответов и вложения. Результаты и ограничения — в [docs/VERIFICATION.md](docs/VERIFICATION.md).

## Размещение и резервные копии

См. [docs/OPERATIONS.md](docs/OPERATIONS.md). Публикация, покупка домена и платные услуги не выполнены. Скрипты `backup.py` / `restore.py` работают через Docker Compose и не используют небезопасную двоичную переадресацию PowerShell.

## Структура

- `app/models.py` — сущности и ограничения уникальности.
- `app/services.py` — выдачи, попытки, посещаемость, минутный журнал и уведомления.
- `app/grading.py` — ограниченный парсер чисел, без eval и алгебраического исполнения.
- `app/main.py` — страницы, формы, серверные права и файлы.
- `app/admin.py` — явный список разрешённых редактируемых полей.
- `app/templates/`, `app/static/` — адаптивный интерфейс и локальные HTMX/KaTeX.
- `migrations/` — версия схемы Alembic; `tests/` — критические сценарии.

## Границы первой версии

Нет онлайн-эквайринга, автоматических сообщений, Google API, ИИ и проверки выражений. Нет email-восстановления пароля: его сбрасывает преподаватель. Календарь — хронологический список, без сетки месяца и генератора повторяющихся встреч. Административные списки рассчитаны на небольшую школу, без пагинации, массового импорта и drag-and-drop конструктора заданий. Очерёдность заданий и ограничение аудитории задаются номерами в формах. Оценка бинарная по заданиям, без произвольных весов. Неизвестные биография, контакты и ссылка Meet заполняются преподавателем; кнопка Meet появляется только после ввода ссылки.


## Подготовка первого реального курса

Данные владельца хранятся локально в `.local-setup/course.json`, исключённом из Git и Docker-образа. Ссылка Meet не попадает в публичную страницу. Применить эти данные к работающему Compose:

```powershell
.\.venv\Scripts\python.exe scripts/apply_course.py .local-setup/course.json
```

Импорт создаёт или обновляет только информацию сайта, выбранный курс и группу. Ученики, занятия с датами, оплаты и домашние работы не создаются. Повторный импорт не дублирует группу и курс. Подробное наполнение программы выполняется после получения учебников. В карточке группы можно редактировать стоимость часа, минимальный и максимальный размер группы и ссылку Meet. При создании обычного занятия с пустой ссылкой используется ссылка его группы.
