# mus.kz — онлайн-обучение математике

Работающее серверное приложение: FastAPI, PostgreSQL, SQLAlchemy/Alembic, Jinja2, HTMX и KaTeX. Русский интерфейс, тенге, отображение расписания в Asia/Qyzylorda. PostgreSQL хранит даты как timestamptz; приложение нормализует их в UTC.

## Запуск через Docker Compose

Требуются Docker Engine / Docker Desktop с Compose v2.

1. Скопируйте `.env.example` в `.env`.
2. Задайте случайный `POSTGRES_PASSWORD` и такой же пароль в `DATABASE_URL`. Для простоты используйте случайную hex-строку без URL-спецсимволов. Задайте независимый `SECRET_KEY` длиной не менее 32 символов, например результат `python -c "import secrets; print(secrets.token_hex(32))"`. Не храните `.env` в Git.
3. Выполните:

```sh
docker compose up -d --build
docker compose exec web python -m app.cli create-admin --email your-email@example.com --name "Ваше имя"
```

Пароль вводится дважды скрыто. Откройте http://127.0.0.1:8000/login. Миграции выполняются при старте web. База не публикуется на порту хоста, сайт привязан к loopback.

Для тестовой установки без реальных данных:

```sh
docker compose exec web python -m app.cli seed-demo
```

| Демо-роль | Email | Пароль |
|---|---|---|
| Преподаватель | teacher@example.test | Teacher-demo-2026 |
| Ученик | student@example.test | Student-demo-2026 |

Все курсы и занятия демо помечены. Начисление 30 минут с нулевой суммой — тестовая запись. Команда повторно не создаёт тот же набор. **Не запускайте seed-demo на публичной рабочей установке**. Начинайте реальную работу с чистой БД и своим администратором.

Сброс пароля:

```sh
docker compose exec web python -m app.cli reset-password --email student@example.com
```

Изменение пароля инвалидирует старые сессии. Преподаватель также может задать новый пароль ученика через карточку ученика; пустое поле оставляет старый пароль.

## Локально без Docker

Python 3.12+ и PostgreSQL 16+ рекомендованы. SQLite поддерживается только для одиночного ознакомления и быстрых тестов, не для конкурентной работы учеников.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\scripts\dev.ps1
```

Скрипт создаёт `local.db`, применяет миграции, добавляет демо и запускает сервер. Если политики PowerShell запрещают запуск скрипта, выполните содержащиеся в нём команды вручную. Системные политики менять не требуется.

Для PostgreSQL перед запуском задайте `$env:DATABASE_URL='postgresql+psycopg://USER:PASSWORD@127.0.0.1:5432/DBNAME'`. База должна быть заранее создана. `.env` при запуске Python напрямую автоматически не читается: переменные задаются в оболочке. В Docker `.env` подключён через Compose.

## Работа преподавателя

Первая версия: публичная страница, набор групп, заявки, расписание/посещаемость, абонементы, шаблоны сообщений и кабинет ученика. Встроенная система заданий удалена; материалы и задания размещаются на Stepik.

1. **Информация сайта** — сведения о преподавателе и контакты. **Курсы** — описание направления и HTTPS-ссылка на Stepik. До появления ссылки кабинет показывает понятное ожидание.
2. **Группы** — расписание, стоимость часа, размер группы, закрытая ссылка Meet, статус набора. Дата начала может оставаться пустой. Заявитель выбирает интересующую группу; преподаватель обрабатывает заявку и создаёт ученика.
3. **Ученики → Состав групп** — выдайте учётную запись и добавьте ученика в группу. Пароль в пустом поле при редактировании не меняется. Снятие членства не удаляет отчёты по уже посещённым занятиям.
4. **Занятия и события** — создайте конкретную дату и длительность. Расписание в карточке группы — описание, отдельные встречи создаются вручную. Укажите планируемые темы, каждую с новой строки. Ссылка Meet по умолчанию берётся из группы.
5. После урока укажите **фактически пройденные темы**, посещаемость каждого ученика и длительность. Можно перенести план в пройденные темы кнопкой и исправить его. Нажмите **Подтвердить проведение**. До подтверждения списаний нет; повторное подтверждение не списывает часы повторно.
6. Присутствие и пропуск без предупреждения списывают фактическую длительность. Пропуск с предупреждением, пробное и отмена — без списания. Изменение посещаемости создаёт корректировку; отмена преподавателем возвращает списанное. Возвраты доступны в истории абонемента.
7. **Абонемент** — запишите полученную оплату: купленные минуты, сумму в тенге и комментарий. 8 часов = 480 минут. Остаток виден ученику в часах и минутах. Отрицательный остаток допустим, минуты не сгорают. Это журнал оплат, не онлайн-эквайринг.
8. **Недельные отчёты** — выбирайте любую неделю. Учитываются только проведённые занятия с отметкой «Присутствовал» или «Бесплатное пробное». Пропущенные уроки не добавляют изученные темы, даже если списаны минуты. Период — понедельник–воскресенье в Asia/Qyzylorda. Пройденные темы можно исправить до/после урока; отчёт обновится автоматически. Старые уроки без тем помечаются как ожидающие уточнения.
9. **Подготовить сообщение** — выберите ученика и неделю: приветствие, напоминание, продление или отчёт. Проверьте, при необходимости исправьте текст и скопируйте его. Отправка вручную. Шаблоны редактируются в одноимённом разделе.
10. **Обзор** — неподтверждённые занятия, новые заявки и нехватка часов. Кабинет ученика показывает ближайшие встречи, остаток часов, отчёты и ссылки Stepik. Результаты заданий со Stepik автоматически не импортируются.

## Проверки

```sh
python -m pytest -q
```

Для полного прогона, включая гонки, задайте `TEST_DATABASE_URL` на отдельную тестовую PostgreSQL. Тесты создают и удаляют только случайные схемы `test_<uuid>`; пользователь БД должен иметь право CREATE SCHEMA.

Результаты проверок и восстановления — в [docs/VERIFICATION.md](docs/VERIFICATION.md).

## Размещение и резервные копии

См. [docs/OPERATIONS.md](docs/OPERATIONS.md). Публикация, покупка домена и платные услуги не выполнены. Скрипты `backup.py` / `restore.py` работают через Docker Compose и не используют небезопасную двоичную переадресацию PowerShell.

## Структура и ограничения

- `app/main.py` — страницы, формы и права доступа.
- `app/services.py` — посещаемость, минутный журнал, оплаты и сохранённая совместимость старых данных.
- `app/reports.py` — отчёт по посещённым занятиям; `app/messages.py` — безопасная подстановка шаблонов.
- `app/admin.py` — разрешённые редактируемые поля.
- `migrations/` — миграции схемы; `tests/` — проверки, включая PostgreSQL-конкурентность.

Календарь пока представлен списком; повторяющиеся встречи не создаются автоматически. Нет автоматической рассылки, эквайринга и синхронизации Stepik. Загрузка фотографий и аватарки отключены. Фото преподавателя и логотип входят в статические файлы сайта. Старые вложения остаются доступными по защищённым ссылкам для совместимости с резервными копиями.

Сайт работает локально в Docker. Публикация на Vercel/другой платформе в это изменение не входит; текущий Compose требует серверного размещения и постоянной PostgreSQL. Упрощение функций само по себе не делает эту установку бесплатным serverless-сайтом.

## Подготовка первого реального курса

Данные владельца хранятся локально в `.local-setup/course.json`, исключённом из Git и Docker-образа. Ссылка Meet не попадает в публичную страницу. Применить эти данные к работающему Compose:

```powershell
.\.venv\Scripts\python.exe scripts/apply_course.py .local-setup/course.json
```

Импорт создаёт или обновляет только информацию сайта, выбранный курс и группу. Ученики, занятия с датами и оплаты не создаются. Повторный импорт не дублирует группу и курс. В карточке группы можно редактировать стоимость часа, минимальный и максимальный размер группы и ссылку Meet. При создании обычного занятия с пустой ссылкой используется ссылка его группы.

Система заданий удалена миграцией `b3a410`: восемь таблиц, модели, автопроверка и выдача работ. Осталось 15 таблиц (включая Alembic); `files` хранит только общие сведения и связь с занятиями. Перед обновлением обязательна полная копия базы и файлов: миграция удаляет учебные данные, а откат возможен восстановлением копии. Локальная копия до удаления: `backups/before-remove-learning/20261018T113439112148Z`; исходники сохранены в `backups/learning-source-before-removal.zip`. Архивы не входят в Git и Docker. Варианты размещения: [docs/HOSTING.md](docs/HOSTING.md).

## Удаление, состав групп и фотографии

- В списках и карточках учеников, курсов, групп, занятий/событий, заявок и шаблонов сообщений есть «Удалить». Перед действием показываются последствия. Запись уходит в корзину своего раздела; восстановление доступно там же.
- Удаление ученика отключает вход и членство в группах, но сохраняет оплаты и историю. После восстановления включите «Активен» и добавьте ученика в нужные группы заново.
- Удаление группы/курса отменяет будущие встречи и отключает членство. Уже проведённые встречи и финансовый журнал остаются. Сначала восстанавливается курс, затем группы и встречи.
- Удаление занятия возвращает списанные за него минуты. После восстановления занятие получает статус «Запланировано»; повторное проведение подтверждается отдельно. Восстановление не списывает минуты.
- «Состав групп»: раскрыть «Добавить учеников в группу», выбрать несколько учеников, нажать «Добавить выбранных». Участника можно убрать без удаления его аккаунта. Кнопка «Создать ученика» создаёт новую учётную запись. Вкладка «Доступ к курсам» удалена.
- «Информация сайта → Фотография преподавателя на главной»: загрузка, замена и удаление публичного снимка. Изображение сохраняется с длинной стороной до 1600 пикселей. Файлы входят в обычную резервную копию Docker volume.

Загрузка фото удалена 18 октября: публичное фото — `app/static/teacher.jpg`, формы и маршруты загрузки отсутствуют. Старые поля путей в БД оставлены для совместимости; новые загрузки невозможны.
